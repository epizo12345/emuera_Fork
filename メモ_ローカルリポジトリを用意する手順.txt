ローカルリポジトリ用のディレクトリを作成する
※どこでもよいのだけれど、例として「C:\work\GitLab」とします。(カッコつけて)コマンドプロンプトで以下のコマンドでディレクトリを作成
mkdir C:\work\GitLab

作成された「C:\work\GitLab」で右クリックして「Open Git Bash Here」を選択
→GitBashをそのディレクトリで起動する

GitLab上のリモートリポジトリをクローンして、ローカルリポジトリを作成する
→「EmueraDotNet」ディレクトリが作成され、その中にいろいろ入る。
git clone https://gitlab.com/alnatiyan/EmueraDotNet.git

作成されたディレクトリへ移動する
cd EmueraDotNet

正常にチェックアウトできたか確認する
git branch

リモートリポジトリのブランチを一覧表示する
git branch -r

リモートリポジトリから特定のブランチを取得する　※例として「SkiaSharp」ブランチ
git checkout SkiaSharp
git checkout BugFix_Test
