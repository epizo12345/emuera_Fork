# 検証済み機能

以下はUX16-07を含む特定の候補と試験条件で確認した範囲です。「確認済み」も記載した経路の確認を意味し、全ゲーム互換を保証しません。候補ごとの正式な自動受入・手動検収状態は、そのcandidateのauthorityで確認してください。

CURRENT ShinEra NEW GAME UX16-07の手動検収は、2026-09-30のリリース準備指示でユーザーからPASSと申告されています。2026-09-29作成の自動受入記録は作成時点の`manualAcceptancePending=true`を保持しており、後日の手動確認を遡って証明するものではありません。両記録の時点と根拠の種類を区別してください。

| 分野 | 判定 | 確認済みの範囲 | 未保証 |
|---|---|---|---|
| 起動 | 確認済み | package取得、root/subpath、タイトル入力準備 | 任意gameIdでの複数ゲーム切替 |
| 入力 | 確認済み（代表経路） | NEW GAME選択、Enter/文字/数値、右クリック送り、held movement、physical repeat | 全要求種別・全画面の入力組合せ |
| 表示 | 部分確認 | HTML、履歴windowing、現在/過去ボタン世代、REDRAW/CLEARLINE代表経路 | 任意HTML・全描画命令 |
| Dungeon | 部分確認 | save219 LOAD、代表移動、HUNT遷移 | 全ダンジョン・全event |
| Battle | 部分確認 | command、ANALYZE cancel、AUTO/REPEAT AUTO、代表勝利復帰 | 全戦闘script/API |
| Save | 確認済み（代表経路） | 通常save、GLOBAL codec、import/export、IndexedDB commit/revision、再起動LOAD | 別origin/profile間の共有 |
| Persistence | 確認済み（代表経路） | FIFO、transaction完了ACK、stale/revision拒否 | IndexedDB等を提供しないブラウザ |
| Special ERB | 部分確認 | TWAIT、INPUTMOUSEKEY、FORCEWAIT等の代表受入 | 全入力構文・全function |
| Graphics | 部分確認 | GSETBRUSH/GSETFONT/GDRAWTEXTと現行NEW GAMEで到達する代表経路 | GDRAWG/GDRAWGWITHMASK、polygon等の未対応APIと任意API組合せ |
| Packager | 確認済み（1.0.1自動試験） | snapshot/diff、template seal、root/subpath、itch ZIP、入力保存保護 | 外部hostingの全設定・外部配布状態 |

## 現行確認の読み方

- 正式状態、対象candidate、試験の合否は当該authorityの`results.json`とraw verificationを正本にします。レポート本文の要約だけを判定根拠にしません。
- 「部分確認」は既知の代表経路が通ったという意味です。同じ機能名を持つすべてのEmuera commandやERBを通した意味ではありません。
- Web graphicsの対応範囲は[既知の制限](09_既知の制限.md)を、セーブの制約は[保存仕様](05_保存・IndexedDB仕様.md)を参照してください。
