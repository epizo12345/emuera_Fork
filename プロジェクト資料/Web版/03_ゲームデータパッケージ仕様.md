# ゲームデータパッケージ仕様

この仕様はPackager 1.0.1とWeb RuntimeのData manifest version 1を基準にします。Packagerの製品バージョンとmanifest versionは別の番号です。

## 入力snapshot

Packagerは選択フォルダから一意なゲームrootを解決し、`Data/ERB`、`Data/CSV`、`emuera.config`を確認します。`emuera.config`は`Data`直下を優先し、なければゲームroot直下を使います。CSV / config、ERB / ERH、設定ファイル、resources CSVとそこから参照される画像・関連resourceを分類します。resources CSVはCP932として読みます。

入力ごとに相対path、size、SHA-256、pack名を記録します。SHAは現在選ばれたbytesと出力の整合確認用です。既知releaseのidentity gateではありません。大文字小文字を無視した論理path衝突、シンボリックリンク、Data範囲外のresource参照は拒否します。`.sav`ファイルと`Data/sav`領域はWeb packageへ含めません。

## p1b-data manifest

manifestはUTF-8 JSONのversion 1で、全体の`totalSize`とファイルごとの`path`、`size`、`sha256`、`pack`を持ちます。pathは相対pathで、大小文字を無視して一意です。1 packの非圧縮source bytesは128 MiBを上限に分割し、ZIPは`CompressionLevel.Optimal`、entry timestampは1980-01-01に固定します。

Runtimeはmanifest version、件数、total size、各pack名、entry path、size、SHAを検証してから隔離stageへ展開します。サイズ上限とpath traversal防止も適用します。これはパッケージ整合性の仕組みであり、ゲーム作者の配布物へ一致を強制しません。

## itch ZIP

itch ZIPはWeb出力root直下に`index.html`、`_framework/`、`p1b-data/`を置き、`<base href="./">`でサブパス配置にも対応します。ZIP内の全entry bytesを生成したWeb出力と再照合します。
