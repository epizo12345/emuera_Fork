# 既知の制限

- 現行Web Runtimeの`gameId`とsave namespaceは`shin-era-tensei-p`前提です。同一originで任意ゲームを安全に切り替える汎用Runtimeではありません。
- 現行ShinEra source auditで呼出箇所が見つかったAPIでも、すべて実行・互換確認したわけではありません。`GDRAWG` / `GDRAWGWITHMASK`、polygon、色取得/設定、PNG保存などに未対応の経路があり、到達時はunsupported APIとして失敗を知らせます。未対応APIのcallsiteがあることと、確認済み経路が壊れていることは区別します。
- `SpriteAnime`を含むGraphics APIにはpartialまたは未対応経路があります。確認済みのsprite frame refreshは、そのAPI全体への対応保証ではありません。
- WebAssemblyに存在しないMS Gothicは同梱DotGothic16へfallbackします。NativeとWebで字形、アンチエイリアス、pixel rasterizationが一致しない場合があります。OFLとfont bytesはsource/Runtime templateに含めます。
- DOM windowingは画面へ出すDOM量を抑えますが、Runtimeのlogical DisplayLines履歴を削除せず、保持メモリを制限しません。
- Webはブラウザ権限・IndexedDB・Web Lockに依存します。ブラウザデータ消去、異なるorigin/profile、private mode等で保存継続が失われる場合があります。
- 主要な広範囲検証対象は現行ShinEraTenseiPです。「全Emueraゲーム完全互換」ではありません。
