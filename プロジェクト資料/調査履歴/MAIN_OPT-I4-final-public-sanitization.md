# MAIN_OPT-I4 — 最終公開サニタイズ

## 目的

公開repositoryの文書から、特定の対話環境やローカル作業状態だけに意味がある記述を取り除き、利用者・開発者に共通する規則へ整理した。

## 整理した文書

- `プロジェクト資料/01_仕様書.md`: 測定値の説明を、特定PCではなく測定環境とセーブに結び付けた。
- `プロジェクト資料/02_引き継ぎ書.md`: 検証対象ゲームの説明、Git運用の原則、ソース配置の記述を一般化した。
- `プロジェクト資料/04_編集ルール.md`: 実装者・検収者に共通する規則へ直し、履歴保全、差分確認、公開前確認を定めた。
- `プロジェクト資料/調査履歴/MAIN_OPT-I3-public-release-preparation.md`: I3の監査範囲と、I4で追加整理した事項を明確にした。

## 一般化した内部運用表現

個別の対話に依存する権限・許可待ちの説明を、差分と検証状態を確認して履歴を管理する一般的な開発規則へ置き換えた。検証対象ゲームの出典は互換性試験という技術的な位置付けを残し、利用者固有の事情や配置に関する説明を除いた。

## 公開監査

- 公開利用者に不要な専用指示: 0件
- 利用者・開発PC固有の絶対パス: 0件。Windows標準の既定ディレクトリ表記はソース内の動作設定として保持
- 不要な個人事情: 0件
- 秘密情報に該当するtracked text: 0件
- 不適切なtracked filename: 0件
- I0 / I1 / I2 / I3報告: 技術判断、commit SHA、検証記録を保持したまま公開用途を再確認
- 資産目録: テスト環境をrepository外の互換性テスト環境として記載済みのため変更なし
