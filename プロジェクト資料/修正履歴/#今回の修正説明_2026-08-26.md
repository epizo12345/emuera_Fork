# Phase 14N1 / 14N2 Graphics native ownership 修正説明

## Phase 14N1

### 背景

SpriteやDIVの長寿命オブジェクトがSKPaintを保持し続けると、retained native objectが増え、長時間表示時のnative memory滞留要因になる。また、GSETBRUSH/GSETPENの呼出側が生成したPaintを直後にDisposeすると、GraphicsImageが保持するownerと寿命が衝突する。

### 実装

ASpriteSingleのpersistent SKPaintを撤去し、描画時のtemporary paintへ整理した。DIVのBorderStyleはPaintではなく色と線幅を保持する値型へ変更した。GSETBRUSH/GSETPENで生成したPaintのownershipをGraphicsImageへ移し、Draw側はfield-owned Brush/PenをDisposeしないようにした。

### 効果

長寿命Sprite/DIVが専用SKPaintを保持し続ける構造を解消し、Brush/Penの寿命をownerへ一元化した。startup A/BではPrivate Memory / Working Setが削減方向となったが、環境依存であり、SKPaint単独の効果量としては未確定である。

### 検証

focused ownership test、startup A/B、save39、save219 smokeをprototypeで実施し、既存の画像描画・save/ERB semanticsに回帰なしを確認した。Release buildは0 errors、既存warning範囲だった。

### 採用状態

正式採用。source commitは`ccbc69a1910a0fb8d732afef81f5efbdfa8aa3bf`、最終配布commitは`35e2bbb3263926de045237f3f50fb21d945cefe8`。当時の正式EXEは24,663,786 bytes、SHA-256は`6CAD66576413725601EE75BDEE4F71028740B09965AC79DDD674F73BA91A3078`。

## Phase 14N2

### 背景

ColorMatrixのSKColorFilter、polygonのSKPath、未設定時のSKFont、negative flip用SKBitmapは描画呼出し単位のtemporary native objectだが、Disposeされない経路が残っていた。反復描画ではfinalizer任せとなり、native objectの解放が遅延して蓄積する可能性があった。

### 実装

`GraphicsImage`のColorMatrix filterとGFillPolygonのSKPathをmethod scopeでDisposeし、GDrawTextでは`_font == null`時に生成したSKFontだけを描画後にDisposeする。`_font != null`のborrowed/cached objectは解放しない。ASpriteSingleのnormal / color-matrix negative flip用SKBitmapも描画完了後にDisposeする。

### 効果

temporary native objectの解放をfinalizer任せにせず、描画完了直後へ明示化した。focused 10,000回級stressは完走したが、native memory削減量、Working Set差、runtime速度差は未測定であり、数値効果は断定しない。

### 検証

diagnostic self-test 4/4、ColorFilter・SKPath・default SKFont・negative flip反復、通常Release 0 errors / 30 existing warnings、正式EXE startup smoke 1/1（Lv2=0）、save39→SHOP→Request一覧・画像表示smokeを確認した。既知のnegative Y挙動、sampling、pixel、flip座標、save/ERB semanticsは変更していない。

### 採用状態

正式採用。source commitは`485f2e37f011234d3d25adcb9e7c5925b0f4c435`。正式EXEは24,663,786 bytes、ProductVersionは`0.2.6.0+485f2e37f011234d3d25adcb9e7c5925b0f4c435`、SHA-256は`45DB53405DD36962485B4537B0FFC7F2641A2F92F264DE3D8E98AB20F0D03F2E`。

### 次

CharacterData、GPU resource cache、dynamic title Sprite等は別課題として扱い、今回のnative disposable cleanupへ混ぜない。
