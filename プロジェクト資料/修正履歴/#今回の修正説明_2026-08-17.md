## 今回変更していない潜在バグ候補

cleanup調査中に既存コードの潜在バグ候補も見つかったが、dead-code削除と挙動変更を同じcommitへ混ぜない方針としたため、今回のProduction変更には含めていない。

代表例:

- `LexicalAnalyzer.ReadSingleIdentifierWord()` のmacro `IDWord` 判定
- `ARRAYMSORT` の3D配列判定とInt64比較
- `GGETCOLOR` / `GSETCOLOR` のY座標下限判定
- `SPRITEGETCOLOR` のARGB合成式
- 現行AngleSharp parserの`<P>` / `<NOBR>`、alignment、`DivState`周辺

これらは再現条件を固定したfocused testを用意し、cleanupとは別のbugfixとして扱う。

## 最終方針

2026-08-17時点では、性能改善後のrepository cleanup / code cleanup Phase 1〜3CをProductionへ反映済みである。

今後は、残るwarningを「安全に整理できるもの」「互換性確認が必要なもの」「潜在バグを示すもの」に分類し、既存バグ候補はfocused test付きの独立修正として進める。
