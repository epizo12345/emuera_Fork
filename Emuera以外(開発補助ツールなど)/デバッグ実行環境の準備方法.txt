--------------------------------------------------------------------------
リモートリポジトリをcloneして、任意の作業場所に開発用repositoryを作成する手順。
--------------------------------------------------------------------------

1. 任意の作業場所でGit Bashまたはコマンドプロンプトを開く。
2. リモートリポジトリをcloneする。

git clone https://gitlab.com/alnatiyan/EmueraDotNet.git
cd EmueraDotNet

3. 必要なbranchを確認してcheckoutする。

git branch -r
git checkout BugFix_Test

--------------------------------------------------------------------------
簡易なデバッグ実行
--------------------------------------------------------------------------

1. repository rootの`Emuera.sln`を開いてDebug buildする。
2. `Emuera以外(開発補助ツールなど)/デバッグ実行用の配置ファイル/1.簡易テスト用(可能な限りファイル数を少なく)/debug_win-x64`を、build outputの`artifacts/bin/Emuera/debug_win-x64`へコピーする。
3. 必要に応じて`artifacts/bin/Emuera/debug_win-x64/Data/ERB/SYSTEM_TITLE.erb`を編集し、ERBに対応する処理を確認する。

--------------------------------------------------------------------------
広い範囲のデバッグ実行
--------------------------------------------------------------------------

1. repository rootの`Emuera.sln`を開いてDebug buildする。
2. 互換性テスト環境のゲームデータを、`Emuera以外(開発補助ツールなど)/デバッグ実行用の配置ファイル/1.簡易テスト用(可能な限りファイル数を少なく)/debug_win-x64`へ配置する。
3. 必要な場合だけ、`2.がっつりテスト用(eraMegatenの本体にテスト用イベントを追加する)/debug_win-x64`をbuild outputの`artifacts/bin/Emuera/debug_win-x64`へ上書きする。

ゲームデータはrepositoryや配布物へ追加しない。
