# Emuera Web Packager — 利用者向け

Emueraゲームフォルダから、ブラウザ用Web packageを作ります。Windows `Emuera.exe`をWebへコピーするツールではありません。入力フォルダは読み取りのみで、出力先へWeb Runtimeとpackageを生成します。

配布用PackagerはGitHub Releasesからruntime-template付きZIPとして入手する方針です。EXE単体では動作に必要なRuntime templateがなく、ZIP全体が必要です。ShinEraや他のゲームデータは添付されません。利用者自身が手元のゲームフォルダをPackagerで別途選択してください。[1.0.3 Release](https://github.com/epizo12345/emuera_Fork/releases/tag/web-packager-v1.0.3)から取得してください。

GitHub Releaseの`EmueraWebPackager-1.0.3-win-x64.zip`を保存し、`SHA256SUMS.txt`でZIPのSHA-256を確認してから展開してください。展開先の`EmueraWebPackager.exe`を起動し、手元のゲームフォルダを選択します。版とチェックサムは上記の正式Releaseページで確認してください。

## 手順

1. `EmueraWebPackager.exe`を起動します。
2. ERB/CSVのあるゲームフォルダ、またはその`Data`フォルダを選びます。
3. 新しい出力先を選び、必要ならitch.io用ZIPを有効にします。
4. 「Web版を作成」を実行し、完了表示を確認します。
5. 出力先の`index.html`をweb serverで開いて確認します。配布する場合はWeb出力一式、または生成したitch ZIPを使います。

初回選択後、Packagerは入力file snapshotを読み、追加・変更・削除を次回生成時に比較します。既存のWeb出力がPackager所有のものなら前版をbackupして置換できます。Packagerが作成したと確認できない出力は上書きしません。別の名前または空の出力先を選んでください。

## データ・保存の注意

- 手作業で変更したERB、CSV、画像もその現在bytesをpackage化できます。既知releaseのSHA一致は要求しません。
- `.sav`と`Data/sav`は配布packageへ含めません。ユーザーの通常saveはブラウザのIndexedDBに保存され、export/importはゲーム画面の保存管理を使います。
- 配布前に生成されたmanifestとpackage検証の完了を確認してください。
- Runtime template、ゲームデータ、セーブを一緒に再配布する権利はそれぞれの配布条件に従います。
- 生成Webの`LICENSE.md`、`licenses/`、`fonts/DotGothic16-OFL.txt`はエンジン・依存・フォントの通知です。配布時に保持してください。これらを同梱してもゲーム・画像・口上の再配布許諾を確認したことにはなりません。

## Preview

PreviewはこのPackagerが起動したlocalhost serverだけを対象にします。Preview停止はPackager自身が開いたlistenerへだけ作用します。既に他のアプリが使っているserverや通常ブラウザのprocessは停止しません。

マクロ実行中は画面上部の赤い「マクロ停止」で残り入力を破棄できます。通常のメッセージ送り停止とは別の操作です。停止後はゲームが安全な入力待ちへ進んだ時点で通常操作を続けてください。有限マクロは戦闘結果等の通常入力待ちで終了することもあります。
