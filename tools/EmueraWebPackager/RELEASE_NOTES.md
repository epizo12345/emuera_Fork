# Emuera Web Packager 1.0.1 — Release Notes

公開前ドラフトです。GitHub Releaseを作成・公開する際に、Release説明欄へ貼り付けてください。

- Windows x64向けself-contained single-file Packagerと、Web Runtime UX16-07のsealed runtime-templateを同梱します。
- Packagerは利用者が選んだゲームフォルダを読み取り、ブラウザ配布用のWeb packageを生成します。
- ShinEra本体、ゲームデータ、セーブデータは含まれません。利用者が使用権を持つゲームフォルダを別途指定してください。
- ZIP全体を展開して利用してください。EXE単体配布ではありません。
